01 / 2026Master's research

Research

ConfoSense

Making building alerts more reliable by giving forecasts a measure of uncertainty.

  • Python
  • Conformal prediction
  • Time series
Inside the project +

The question

Accurate forecasts alone do not tell a building operator which deviations deserve attention.

The approach

A common evaluation protocol links forecasting, conformal intervals, and causal alert generation across building temperature, energy, and HVAC tasks.

What it demonstrates

Evaluates fault detection, alert workload, detection delay, robustness, and recalibration. The contribution is a monitoring methodology and empirical validation.

Results are bounded to the declared datasets and synthetic-fault protocols. This is research evidence, not a deployed building-control system.

  • Embedded systems

Inside the project +

04 / 2026Hackathon MVP

AI & Software

ProcurePilot

A procurement copilot for decisions where price is only part of the story.

  • Next.js
  • TypeScript
  • Agentic AI
Inside the project +

The question

SME buyers need to weigh lead time, availability, and supplier risk during supply disruptions.

The approach

A transparent scoring model ranks regional supplier profiles, with adjustable weights, substitute options, and risk explanations.

What it demonstrates

A working MVP with seeded requests, supplier comparisons, SQLite persistence, and a Lua-backed assessment flow.

Supplier data and negotiation scenarios are demonstrations. The repository documents the configuration required for live agent services.

AI & Software

RoomLab

A shared molecular playground that makes learning a team activity.

  • TypeScript
  • WebSocket
  • Spatial learning
Inside the project +

The question

Collaborative spatial experiences need shared ownership, alignment, and meaningful learning tasks.

The approach

Learners assemble molecules, inspect geometry, and answer synchronized quizzes in a shared browser scene.

What it demonstrates

A browser simulator, authoritative room-state model, relay server, ownership rules, and late-join hydration.
