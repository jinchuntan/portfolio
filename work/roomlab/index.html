RoomLab.

A shared molecular playground where learners build, reason and answer questions together. A browser prototype for collaborative learning.

Spatial learning prototypeShared-state prototype and collaborative learning workflow.

Project details

  • TypeScript
  • WebSocket
  • Spatial learning
View repository ↗

The problem

Collaborative spatial experiences need shared ownership, alignment, and meaningful learning tasks.

My contribution

I built a browser simulator around shared molecule assembly, synchronized quizzes and an authoritative room-state model. Object ownership and late-join hydration help keep participants in the same learning experience.

The outcome

The repository provides the browser simulator and WebSocket relay. Browser-native transport demonstrates multiple tabs on one device; multi-device sessions require the external relay. Spectacles alignment is mocked.

A browser simulator, authoritative room-state model, relay server, ownership rules, and late-join hydration.

Scope & status

Spectacles and Lens Studio integrations use adapter interfaces and mocked alignment. The playable demonstration is the browser simulator.
