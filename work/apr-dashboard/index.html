APR Dashboard.

Turning chip implementation and timing reports into one consistent view of engineering progress. Built around structured submissions and documented metrics.

The problem

APR and static timing metrics need consistent structure before engineers can compare progress and identify problems.

My contribution

I built structured submissions, validation rules and a static HTML dashboard for APR and static timing analysis. The public example demonstrates the path from saved JSON to project, history and record views.

The outcome

The implementation includes documented metric contracts and runnable examples. It is a reporting tool; live report parsing and production flow integration are outside the public prototype.

A public implementation with submission examples, documented schemas, and dashboard generation.

Scope & status

The portfolio links to the public tool. No employer design databases, internal reports, or proprietary chip results are included.
